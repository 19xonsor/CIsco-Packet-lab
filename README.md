This repository documents my networking homelab projects focused on developing practical network engineering skills using both simulation and real enterprise hardware. The lab environment includes devices such as a Cisco ISR 4331 router, Cisco Catalyst WS-C3850 switch, and an Aruba 3810M Layer 3 switch. The projects demonstrate configuration and troubleshooting of VLANs, inter-VLAN routing, router-on-a-stick, dynamic routing protocols such as OSPF and RIPv2, IP addressing, and console-based device management. These labs are used to practice real-world networking concepts, network segmentation, and infrastructure design relevant to CCNA-level networking and data center environments.
